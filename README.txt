EDITING
  Search the .html files for "EDIT ME" to find every spot to fill in.
  Dashed boxes and grey italic text are placeholders. To swap a dashed box
  for a photo, replace the <div class="slot">...</div> with, for example:
      <img src="images/profile.jpg" alt="Photo of Brian Al P. Tenorio">
  Colours are at the top of css/style.css.

PUBLISHING ON GITHUB PAGES
  1. Create a new public repository on GitHub.
  2. Upload everything inside this folder (not the folder itself).
  3. Settings > Pages > Deploy from a branch > main / (root) > Save.
  Your site appears at https://<your-username>.github.io/<repository-name>/
